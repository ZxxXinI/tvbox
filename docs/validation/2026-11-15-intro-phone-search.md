## 三、用户实机验收清单（尚未执行）

### 片头设置与播放

- [ ] 设置 → 默认跳过片头：初始为 0 秒；设置 30 秒，重启后仍保留。
- [ ] 播放页 → 片头：选跟随全局，从头播放及下一集跳至约 30 秒。
- [ ] 本片设 60 秒，其它影片仍跟随全局；本片所有集共用，正常切换播放线路不改变设置归属。
- [ ] 本片“不跳过”可覆盖非零全局值；重新选择“跟随全局”可移除覆盖。
- [ ] 自定义 0–600 秒可保存，±5 秒按钮可由遥控器使用，空值／越界不能保存。
- [ ] 控制栏上一／下一集、选集、数字 1/3 及播完自动连播都按新集规则处理。
- [ ] 手动退回片头不会再次被跳走；播放中改设置不立刻改变当前进度。
- [ ] 首页继续观看／历史续播保持原进度；手动／自动换线保持进度及暂停状态。
- [ ] 片头设置长于视频时长或视频不可跳转时正常播放，不直接跳到结尾；切后台或音频中断不因片头逻辑自动续播。
- [ ] 菜单倍速、左右每次 10 秒及长按连续快进等原有遥控器行为不变。

### 手机扫码搜索

- [ ] 默认主题和影院主题：搜索页可用遥控器聚焦“手机扫码输入”，二维码清晰可扫。
- [ ] 盒子和手机局域网互通时，扫码打开输入对话框式网页，显示输入提示、输入框和提交按钮；无麦克风请求。
- [ ] 输入中文影片名并提交：电视关闭二维码并直接搜索；手机显示已发送；首个结果可用遥控器操作，无结果时可返回搜索入口。
- [ ] 连点／重复提交只触发一次；空白输入有提示且不消耗会话。
- [ ] 成功提交、取消、退出搜索页或切后台后旧二维码不能再使用，重新打开得到新二维码。
- [ ] 约 5 分钟后提示失效，可以重新生成；没有局域网地址时明确提示，不给出 127.0.0.1 二维码。
- [ ] 搜索后进入详情并返回，恢复原结果卡片，不被扫码后的首次焦点处理反复拉回第一项。
- [ ] 不同手机扫码器／浏览器、实际路由器访客隔离和有线／Wi-Fi 互通效果由用户确认；没有通过公网中转绕过局域网隔离。
