## 遥控器快捷键

首页保留数字键快捷键：

- `1`：历史
- `2`：搜索
- `3`：推荐
- `4`：电视
- `5`：平台直播
- `6`：设置

这些快捷键与当前主题无关，切换到影院主题后仍然可用。
